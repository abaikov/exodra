"Rows are matched by key, and the key rules are ours"

Both panels render the same rows from the same data. The left one is the core's own list — reconcileExoOrder called from an effect, which reconciles by object identity. The right one opens c.keyedList instead and matches rows by item.id.
Press Refetch: the data comes back as freshly parsed objects, the way a poll returns it. Nothing on the left is the same object any more, so every row is rebuilt. Every row on the right is matched by its key and kept — the build stamps stand still.
A pack, EXO_KEYED_LIST_VOCABULARY from @exodra/list-reconcile, composed with composeExoPlugins: it puts c.keyedList on every exonode the backend builds. A backend without it has no such method. Both panels stand on c.childList, which is the withExoChildList pack from @exodra/dom.

Core — reconciled by identity

reconcileExoOrder(c.state.rows, c.state.shown, want, want, build)

Pack — reconciled by key

c.keyedList(P.rows, item => item.id, build, update).reconcile(want)
