Form controls, one listener, no bound model

One machine. The <form> carries one input event port, and every field inside it reports through it — text, number, checkbox, radio and select all fire input: readExoControlValue(event.target) reads the field, and a function the handler calls writes the read-out on the right. Nothing writes a field's value back while you type — the browser already holds it.
the packages: @exodra/core · @exodra/dom · @exodra/forms

What to try

Type in the fields and watch the live read-out. Empty the age field: it reads NaN, not 0. Press Send: the submit read-out comes from readExoControlValues over the ref ports, read at that moment, not from the live state. Fill from code and Clear from code are the programmatic direction: a function the handler calls writes the value and checked ports, and writeExoChoice puts the radio and option marks on the chosen value in one write each — the browser clears the rest of the group. The submit read-out also reads the two radios through their ref ports: the unchecked one comes back undefined. Clear is the case that needs a property write: the attribute was empty all along, so an attribute write would leave your text on screen.
